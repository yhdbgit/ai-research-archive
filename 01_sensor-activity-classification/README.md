# IMU 센서 기반 환자 활동 상태 분류 (Sensor Activity Classification)

> **"사전 학습(Pre-trained) 모델의 한계를 극복하고, 데이터 정규화와 파인튜닝(Fine-Tuning) 전략을 통해 1D 시계열 데이터를 2D 비전 모델에 최적화한 프로젝트입니다."**

## 1. 프로젝트 개요
* **프로젝트명**: IMU 센서(가속도) 기반 환자 6가지 활동 상태 예측 모델 개발
* **진행 기간**: 2025. 11 ~ 2025. 12 (대학교 인공지능 텀 프로젝트)
* **목적**: 1D 시계열 센서 데이터를 CWT(Continuous Wavelet Transform)를 통해 2D 이미지로 변환하고, CNN 모델(ResNet18)을 활용해 환자의 행동을 고정밀로 분류
* **사용 기술**: `PyTorch`, `ResNet18`, `Numpy`, `Pandas`
* **주요 성과**: 초기 베이스라인 대비 **정확도(Accuracy) 약 30% 향상 (0.61 ➔ 0.802)**

---

## 2. 핵심 문제 해결 과정

단순히 제공된 모델을 실행하는 것에 그치지 않고, 데이터의 특성과 모델 아키텍처 간의 불일치를 분석하여 성능 병목을 해결했습니다.

### Problem: 사전 학습 모델과 센서 데이터 간의 도메인/스케일 불일치
* **상황**: 초기 베이스라인 코드에서 ResNet18의 백본을 동결(Freeze)하고 분류기만 학습시켰을 때, 학습 손실(Loss)이 더 이상 떨어지지 않고 **정확도가 0.61 수준에 정체**되는 현상이 발생했습니다.
* **원인 분석 (근본 원인 파악)**: 
  1. **데이터 스케일 불일치**: 변환된 CWT 텐서 데이터의 값이 `-0.005 ~ 0.007` 사이의 매우 작고 음수가 포함된 비정형 분포를 띠고 있었습니다. 반면 ImageNet으로 사전 학습된 ResNet은 `0~1` 사이로 정규화된 픽셀 분포를 기대하므로 피처(Feature)를 제대로 추출하지 못했습니다.
  2. **도메인 차이**: 자연 이미지(동물, 사물 등)를 학습한 필터가 시계열 센서 데이터의 고유한 주파수/시간적 패턴(Texture)을 잡아내는 데 한계가 있었습니다.

### Action & Trade-off: 커스텀 전처리 파이프라인 및 학습 전략 수정
이를 해결하기 위해 두 가지 핵심 엔지니어링 의사결정을 내렸습니다.

1. **Min-Max 정규화(Normalization) 직접 구현**
   * Pytorch의 `Dataset` 클래스 내부에서 입력 텐서의 최솟값과 최댓값을 추출하여 **`0.0 ~ 1.0` 사이의 균일한 분포로 강제 매핑**하는 전처리 로직을 추가했습니다. 
   * 이를 통해 모델이 가중치를 업데이트할 때 기울기 소실(Vanishing Gradient) 없이 안정적으로 학습할 수 있는 환경을 구축했습니다.

2. **학습 전략 변경 (Freeze ➔ Full Fine-Tuning) 및 트레이드오프**
   * **Trade-off 고민**: 백본 동결(Freeze)을 해제하고 전체 레이어를 미세조정(Full Fine-Tuning)하면 학습 시간과 연산 비용이 크게 증가합니다. 
   * **의사결정**: 하지만 센서 데이터라는 '새로운 도메인'의 특징을 모델이 완벽히 학습(Representation Learning)하는 것이 더 중요하다고 판단하여, 학습 속도를 일부 포기하더라도 **전체 파라미터를 업데이트하는 파인튜닝 전략을 채택**했습니다.

### Result: 정량적 성능 향상
* 데이터 분포 최적화와 파인튜닝 도입 결과, 모델이 CWT 이미지의 패턴을 명확히 학습하며 훈련 손실(Loss)이 급격히 안정화되었습니다.
* 최종 분류 정확도 **0.802**를 달성하며 초기 베이스라인(0.61) 대비 성능을 약 **30% 이상 폭발적으로 향상**시켰습니다.

## 4. 회고 및 직무 적합성

* **데이터 엔지니어링의 중요성 체감**: 아무리 뛰어난 SOTA(State-Of-The-Art) 모델이라도, 입력되는 **데이터의 스케일(Scale)과 분포를 모델의 아키텍처에 맞게 정제하지 않으면 제 성능을 낼 수 없음**을 깊이 깨달았습니다. 
* **비즈니스 임팩트 (응용 가능성)**: 1D 시계열 데이터를 2D 이미지로 변환하여 비전 모델로 푸는 접근 방식은 향후 제조 공정의 센서 이상 탐지나 트래픽 분석 등 **다양한 산업군의 시계열 데이터 분석 문제에 유연하게 재사용할 수 있는 핵심 역량**이 될 것입니다.
